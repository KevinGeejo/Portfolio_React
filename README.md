# Kevin Geejo - Full Stack Developer Portfolio

A modern, responsive portfolio website built with React and Tailwind CSS, showcasing Kevin Geejo's web development projects and professional experience.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **SEO Optimized**: Meta tags, structured data, and semantic HTML
- **Performance**: Optimized images and lazy loading
- **Accessibility**: ARIA labels and semantic markup
- **Modern UI**: Beautiful animations and hover effects
- **Cross-browser Compatible**: Works on all modern browsers

## 🛠️ Technologies Used

- **Frontend**: React 18, Tailwind CSS
- **Icons**: Font Awesome, React Icons
- **Animations**: React Typed, React Scroll
- **SEO**: React Helmet Async
- **Build Tool**: Create React App

## 📱 Sections

1. **Hero Section**: Introduction and call-to-action
2. **About Section**: Professional background and experience
3. **Projects Section**: Portfolio of development work
4. **Contact Section**: Professional links and resume

## 🔧 Installation & Setup

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation Steps

```bash
# Clone the repository
git clone https://github.com/yourusername/kevin-portfolio.git

# Navigate to project directory
cd kevin-portfolio

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## 📊 SEO Features

- **Meta Tags**: Comprehensive meta descriptions and keywords
- **Open Graph**: Social media sharing optimization
- **Twitter Cards**: Enhanced Twitter sharing
- **Structured Data**: JSON-LD schema markup
- **Sitemap**: XML sitemap for search engines
- **Robots.txt**: Search engine crawling instructions
- **Canonical URLs**: Prevent duplicate content issues
- **Semantic HTML**: Proper heading hierarchy and landmarks

## 🌐 Deployment

### Build the Project

```bash
npm run build
```

### Deploy to Netlify

1. Connect your GitHub repository to Netlify
2. Set build command: `npm run build`
3. Set publish directory: `build`
4. Deploy!

### Deploy to Vercel

1. Install Vercel CLI: `npm i -g vercel`
2. Run: `vercel`
3. Follow the prompts

## 📝 Customization

- Modify `public/index.html` for meta tags
- Update `public/manifest.json` for PWA settings

- Modify Tailwind classes in component files
- Update color scheme in `tailwind.config.js`
- Customize animations and transitions
